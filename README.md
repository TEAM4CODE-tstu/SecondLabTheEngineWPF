# Лабораторная работа №2 — «Движок слабейшего предусловия (wp) для последовательности и if»

## Что это?
Данное приложение представляет собой интерактивную настольную систему для демонстрации концепции **исчисления предикатов** и **формальной верификации программного обеспечения** (анализ программ как преобразователей предикатов) в пользовательских интерфейсах. 

Проект наглядно показывает, как на основе:
* Заданного постусловия (**Post**)
* Исходного кода фрагмента (последовательности присваиваний и ветвлений `if-else`)

Автоматически вычисляется, визуализируется и проверяется **наименьшее предусловие** (*Weakest Precondition / wp*), формируя итоговую **триаду Хоара** для строгого доказательства корректности алгоритма.

## Описание
В качестве сквозного сюжета для бизнес-логики выбран модуль **«Логистика и учет грузов»**. Приложение содержит три взаимосвязанные операции:
* **Контроль перегруза (Мин/Макс)** — определение критических весовых границ отдельных грузов в партии.
* **Оптимизация погрузки** — распределение или упорядочивание объектов по весовым категориям.
* **Расчёт общей массы рейса** — агрегация суммарного веса всей последовательности прибывших грузов.

Если в рамках первой лабораторной работы контракты проверялись динамически во время выполнения, то в текущей версии фокус смещен на **статический анализ кода фрагментов**. 

На основе заданного постусловия алгоритма приложение автоматически рассчитывает **наименьшее предусловие (wp)** с помощью исчисления Дейкстры. Результаты пошагового вывода формул и итоговая триада Хоара мгновенно отображаются пользователю, демонстрируя математическую гарантию безопасности выполнения кода еще до его фактического запуска.


## Использованные технологии
* **Платформа:** .NET 8 
* **Язык программирования:** C# 12
* **Графическая подсистема:** Windows Presentation Foundation (WPF) 
* **Архитектурный паттерн:** MVVM (Model-View-ViewModel) 
* **Юнит-тестирование:** xUnit (покрытие граничных случаев)

## Установка
1. Склонируйте репозиторий вашей команды на локальный компьютер:
   ```bash
   git clone https://github.com
   ```
2. Перейдите в корневую папку проекта:
   ```bash
   cd Lab1Contracts
   ```
3. Откройте файл решения `Lab1.slnx` (или `Lab1.sln`) в Visual Studio.
4. Восстановите пакеты NuGet и соберите проект (`Ctrl + Shift + B`).

## Как пользоваться приложением
1. **Выбор операции:** В левой панели меню выберите интересующий алгоритм (например, «Сортировка массива»).
2. **Ввод данных:** В правой карточке операции введите массив чисел через пробел, запятую или точку с запятой.
3. **Контроль Pre-условий:** Обратите внимание на круглый индикатор «Предусловие». Если ввод некорректен (например, поле пустое), индикатор загорится красным. Если все требования соблюдены — зеленым.
4. **Выполнение:** Нажмите кнопку **«Выполнить»**. Алгоритм обработает данные, выведет результат в поле ниже, а индикатор **«Постусловие»** подтвердит математическую корректность выполнения операции.
5. **Просмотр контракта:** Нажмите кнопку **«Показать контракт»**, чтобы открыть модальное окно. Там подробно расписаны формальные правила Pre/Post условий, возможные исключения и граничные примеры.
6. **Выход:** Для безопасного и корректного закрытия приложения используйте встроенную кнопку **«Выход»** внизу левой панели меню (системный крестик окна заблокирован в целях демонстрации управления жизненным циклом программы).
